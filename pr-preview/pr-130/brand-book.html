0002 · One Kotlin Multiplatform core for every platform

0008 · A curated catalog with stable slugs, updated without an account

0009 · Shared plans are saved synced or as a copy; enrollments pin a version

0010 · Treadmills are read-only metric sources in v1

0011 · A .FIT file export instead of Garmin and Strava APIs

0012 · Design tokens are generated from one file

0013 · Workouts have a format, not a type
