Lucide is the icon set everywhere ​

Every icon in Coach Poulpy comes from Lucide: the websites, the web mockups and docs site (ADR 0023), the phone and tablet mockups, and the Android and iOS apps. One set means one drawing style, one stroke weight and one name for each action, whatever the platform.

What it means ​

  • A new icon is taken from Lucide by its Lucide name (calendar, chevron-left, circle-exclamation-point), using the name Lucide lists first rather than one of its older aliases (circle-alert, history). A platform never draws its own icon for an action Lucide already has.
  • Every platform draws the same Lucide version: the one web/ui pins for @lucide/vue.
  • Vue uses @lucide/vue, the official package (it replaced lucide-vue-next, now deprecated): <ChevronLeft class="size-5" aria-hidden="true" />.
  • Web, phone and tablet mockups stay plain HTML (ADR 0016): an icon is the Lucide SVG copied inline, with data-lucide="<name>". design/check-mockups.mjs fails CI when an icon has no name or is not drawn as that Lucide icon.
  • Android and iOS use no Lucide package. design/icons/ keeps a copy of each Lucide SVG the product uses, taken unchanged from lucide-static, and design/build-icons.mjs writes them for the apps: a Lucide object of Compose ImageVectors on Android (Lucide.ChevronLeft), and template vector images in Assets.xcassets/Lucide with a Lucide enum and a LucideIcon view on iOS (LucideIcon(.chevronLeft, size: 20), Label("action.delete", lucide: .trash)). node design/build-icons.mjs --add <name> copies a new icon in; CI runs the script with --check.
  • Icons keep Lucide's drawing: a 24 box and a 2 wide round stroke, scaled with the icon. The apps size them in points or dp like any icon (24 by default, 16 to 20 beside text).
  • Poulpy's drawings are not icons. They stay generated by design/build-poulpy.mjs (ADR 0012), and so are the body map figures.
  • Icon colour comes from the colour roles in the design system, never a raw palette step. An error keeps its icon: crimson, with words.

Why ​

  • A person who learns one icon meaning in the app finds the same one on the website and in the docs.
  • One set can be used across Vue, Compose and SwiftUI with the same names, so mockups, screens and sites can be compared directly.
  • Lucide is open source under the ISC licence for its code. Most of its icons come from Feather and are under the MIT licence, which both allow use in the app and sites (Lucide license). design/icons/LICENSE is Lucide's licence, kept with the copies.
  • Lucide publishes no Compose or SwiftUI package, and lists none for them among its third-party packages (checked on lucide.dev/packages in November 2026). The community ports found were weighed against copying the SVGs:
    • com.composables:icons-lucide (composablehorizons/compose-icons, MIT) last released in December 2025, eleven months and many Lucide releases behind; Lucide renames icons between releases, so its names already differ from @lucide/vue's.
    • io.github.thelacspace:lucide-compose (Apache 2.0) has one maintainer, two stars and no release since May 2026.
    • JakubMazur/lucide-icons-swift (ISC) follows Lucide's releases automatically, but ships all of Lucide's icons as UIImages by id, with no SwiftUI view, and would be a second version to keep in step with the web.
    • Copying the SVGs keeps both apps on exactly the web's version and names, ships only the icons in use, adds no dependency, and is the same generator pattern as the theme, Poulpy and the body map (ADR 0012). Updating Lucide is raising @lucide/vue in web/ui and copying the icons again.

Consequences ​

  • The Android app no longer depends on material-icons-extended; iOS no longer uses SF Symbols for icons.
  • An SF Symbol scaled with the text around it; a Lucide image on iOS has a fixed size, so each place says its size.
  • A screen or mockup that needs an icon Lucide lacks says so in its PR. The fix is a new drawing in design/ that matches Lucide's stroke, not a different set. The movement-pattern badges and the treadmill have no exact Lucide match today: they use the nearest Lucide icon (see the design system) until real exercise pictures replace the badges.
