0001 · Local-first: the phone is the source of truth

0002 · One Kotlin Multiplatform core for every platform

0003 · Sessions are stored as append-only event logs

Decisions ​

Architecture decision records: each one says what was decided and why, in a paragraph or two. They live in docs/adr/, and a new one is added in the same PR as the change it explains. Agents read the ones touching their area before working there. Brand decisions (logo, colours, moods, poses) are traced on their own page, Brand decisions.
