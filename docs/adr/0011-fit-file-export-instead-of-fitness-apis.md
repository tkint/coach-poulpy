# A .FIT file export instead of Garmin and Strava APIs

Strava now requires a paid subscription to create an API app, and Garmin has paused new developer applications. v1 therefore exports a standard .FIT file per session, which imports for free into both Garmin Connect and Strava; Apple Health and Health Connect are optional switches. Direct links can come later without changing the session model.
