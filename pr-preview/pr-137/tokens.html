Architecture

Overview

Glossary

Decisions

0001 · Local-first: the phone is the source of truth

0002 · One Kotlin Multiplatform core for every platform

0003 · Sessions are stored as append-only event logs

0004 · Workout types are modules over one engine

0005 · Ids are UUIDv7 made on the device

0006 · Sync keeps both conflicting edits

0007 · Postgres: columns for structure, JSONB for content

0008 · A curated catalog with stable slugs, updated without an account

0009 · Shared plans are saved synced or as a copy; enrollments pin a version

0010 · Treadmills are read-only metric sources in v1

0011 · A .FIT file export instead of Garmin and Strava APIs

0012 · Design tokens are generated from one file

0013 · Workouts have a format, not a type

0014 · Text lives in one JSON file per language and namespace

0015 · Catalog text lives in translation files

0016 · Mockups are plain HTML in the repo
