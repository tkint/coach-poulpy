Design tokens ​

tokens.json is the single source for Coach Poulpy's colours, mood shades, type scale, spacing, radius and motion. Edit it, then regenerate the platform files:

sh
node design/build-tokens.mjs
Generated fileUsed by
app-android/.../ui/PoulpyTokens.ktCoachPoulpyTheme (Material 3 colour scheme, typography, shapes) plus PoulpyPalette, PoulpyMood, PoulpySpace, PoulpyRadius, PoulpyMotion
app-ios/CoachPoulpy/Theme/PoulpyTokens.swiftPoulpyColor (light and dark), PoulpyPalette, PoulpyMood, PoulpyFont, PoulpySpace, PoulpyRadius, PoulpyMotion
app-ios/.../AccentColor.colorset/Contents.jsonThe iOS accent colour (buttons, links, toggles)
web/ui/src/tokens.cssCSS custom properties (--cp-*), with dark values under prefers-color-scheme, and cp-theme-light / cp-theme-dark to pin one theme on part of a page. The websites' DaisyUI theme (web/ui/src/theme.css) points at them (ADR 0023)

CI runs node design/build-tokens.mjs --check and fails if a generated file no longer matches tokens.json.

Colour rules:

  • The poulpy colours (blue, ember, ink) are the mascot's fabric and are the same in light and dark.
  • The blue side (mood.proud, mood.happy, mood.recovering) means the plan is on track; the ember side (mood.annoyed, mood.grumpy, mood.fuming) means a session slipped.
  • The plush blue and ember are too light for white text: buttons use primary (lagoon 600) and grumpy (ember 600).
  • error is a crimson, always shown with an icon and text, so it is never confused with a grumpy Poulpy.

The brand fonts are Baloo 2 (headings) and Nunito (body). The website loads them from Google Fonts. The apps bundle one static file per weight listed under font in tokens.json, in app-android/src/main/res/font and app-ios/CoachPoulpy/Fonts. After changing those weights, rebuild the files and the theme:

sh
pip install fonttools
python3 design/fonts/build-fonts.py
node design/build-tokens.mjs

On iOS, also list any new file under UIAppFonts in Info.plist. Views use .font(.poulpy(.headline)) instead of .font(.headline) to get the system text styles in the brand fonts. Both fonts are under the SIL Open Font License (design/fonts/OFL-*.txt).

Body map figures ​

build-body-map.mjs draws the front and back muscle chart in both builds (wider shoulders, wider hips) and writes it into the profile screens' stories (profile-pain-sheet, profile-body-figure-sheet) and into design/body-map.json, which the apps read. The muscle outlines come from design/body-map-source/parts.json, adapted from the MIT-licensed hugobonifay/body-map (see design/body-map-source/NOTICE.md); the script turns them into plain curves, names each muscle, stretches the builds and leaves the skin transparent. To change a muscle, edit the script or the source outlines, then run:

sh
node design/build-body-map.mjs

Poulpy's drawings ​

build-poulpy.mjs draws the loading animation's top view and the themed (one-colour) layers of the app icons with the brand book's own drawing code, and writes them for each platform. His moods, poses and app icons are pictures of the 3D model, from build-poulpy-pictures.mjs:

sh
node design/build-poulpy.mjs
Generated fileUsed by
design/poulpy/*.svgReference copies of the loader
app-android/src/main/res/drawable/poulpy_loader*.xmlThe loader as Android vector drawables
app-ios/CoachPoulpy/Assets.xcassets/Poulpy/PoulpyLoader*.imagesetThe loader as iOS vector assets
app-android/src/main/res/drawable-nodpi/poulpy_*.pngHis moods and poses as Android pictures (R.drawable.poulpy_pose_champion), from build-poulpy-pictures.mjs
app-ios/CoachPoulpy/Assets.xcassets/Poulpy/Poulpy{Mood,Pose}*.imagesetHis moods and poses as iOS 3x pictures (Image("PoulpyPoseChampion")), from build-poulpy-pictures.mjs
app-android/src/main/res/drawable-nodpi/ic_launcher_[<id>_]foreground.png, drawable/ic_launcher_background.xml, drawable/ic_launcher_[<id>_]monochrome.xml, mipmap-anydpi-v26/ic_launcher[_<id>].xmlThe Android launcher icon: an adaptive icon with a Deep sea background, a picture of Poulpy and a themed (monochrome) silhouette layer
app-ios/CoachPoulpy/Assets.xcassets/AppIcon[<Id>].appiconsetThe iOS app icon: 1024 px PNGs for light, dark and tinted; the light and dark are alike, on Deep sea. The alternate icons Settings › App icon offers (proud, annoyed, grumpy, champion, cocky) are the sets with an id

Moods and poses are 744 × 678 pictures (the 3x of a 248 × 226 frame), so they can replace each other without moving. The loader (loader, and loader_small with a thicker line for sizes under 32) is Poulpy seen from above as a blue outline of eight round lobes with short tails; PoulpyLoader on Android and iOS turns it clockwise once every 2.4 s (10 s when animations are reduced) and replaces the old Spinning pose. CI runs it with --check too. The shared PoulpyDrawing enum names each drawing, and PoulpyCoach picks which one Today shows.

The app icon is the 3D happy blue Poulpy on Deep sea (theme.dark.background), the same in light and dark, so it works whichever theme the phone is in; the tinted iOS icon is its greyscale. On iOS he is scaled to fill 80 % of the square. On Android, he is scaled so his farthest point sits on the 66 dp circle every launcher mask keeps; the themed icon is still his drawn silhouette at half strength with the eyes and smile at full. The pictures are painted in plain JavaScript so every machine gets the same pixels; --check compares those pixels, not the compressed bytes.

The alternate icons use the mood or pose picture of the same name, scaled the same way, so a pose with props or confetti draws Poulpy smaller. Their ids are those of AppIcon in the shared code and never change. Android switches between launcher aliases in the manifest; iOS lists the sets in ASSETCATALOG_COMPILER_ALTERNATE_APPICON_NAMES in app-ios/project.yml.

Poulpy in 3D ​

poulpy-3d/model.mjs describes Poulpy's 3D shape in plain JavaScript, with no dependency: the proportions (SHAPE), his faces (FACES), his six moods (MOODS) and how he is lit and shaded (LOOK) sit at the top of the file. poulpy-3d/poses.mjs gives him his twelve poses, with what he wears and the effects around him. poulpy-3d/motion.mjs describes how he moves the same way: TURN is his idle, turning around in short steps with soft arms that trail and settle. JUMP is his little jump, CHEER the champion's jumps of joy, with his medal and confetti, and WINK the cocky one's wink, with his stars; they run live in the component workshop and are not written into the glTF files yet. build-poulpy-pictures.mjs paints his six moods and twelve poses as PNGs in poulpy-3d/pictures, with poulpy-3d/picture.mjs, in plain JavaScript so every machine writes the same pixels; CI checks them with --check too. build-poulpy-3d.mjs writes both as binary glTF files, one per side standing still and one per side moving, with his colours from tokens.json:

sh
node design/build-poulpy-3d.mjs
Generated fileUsed by
design/poulpy-3d/poulpy_blue.glbThe blue, smiling side, for any 3D tool or engine
design/poulpy-3d/poulpy_ember.glbThe ember, grumpy side
design/poulpy-3d/poulpy_blue_turn.glbThe blue side, rigged, with the animation turn
design/poulpy-3d/poulpy_ember_turn.glbThe ember side, rigged, with the animation turn

The script writes the files itself, byte for byte the same on every machine, and CI runs it with --check. The Brand > Poulpy in 3D page of the component workshop (web/storybook/stories/brand/poulpy-3d.md and the live model) draws the same model.mjs and runs the same motion.mjs live, lists the rules of the shape and of the move and says how to reuse it; the apps do not use the model yet.

The rules for using Poulpy are in web/storybook/stories/brand/brand.md; the full brand book is in web/storybook/stories/brand/brand-book/ and on the Brand > Brand book page of the component workshop, and the decisions behind it are in web/storybook/stories/brand/brand-decisions.md.

Icons ​

Every icon is from Lucide (ADR 0024). icons/ holds a copy of each Lucide icon the product uses, unchanged from the lucide-static package at the version web/ui pins for @lucide/vue, with Lucide's licence (icons/LICENSE). build-icons.mjs writes them for the apps:

sh
node design/build-icons.mjs --add calendar-plus   # copy a Lucide icon in, then write
node design/build-icons.mjs                       # write the apps' icons again
Generated fileUsed by
app-android/.../ui/Lucide.ktCompose ImageVectors, one per icon (Icon(Lucide.CalendarPlus, …))
app-ios/CoachPoulpy/Lucide.swiftThe Lucide enum (.calendarPlus), the LucideIcon view and Label(_:lucide:)
app-ios/CoachPoulpy/Assets.xcassets/Lucide/*.imagesetiOS template vector images (LucideCalendarPlus)

The websites and the phone mockups take the same icons from @lucide/vue by name (MobileIcon in the phone stories), so a mockup cannot draw an icon other than the one it names. CI runs build-icons.mjs --check, which also fails when an image set is left over from an icon no longer in icons/. To move to a newer Lucide, raise @lucide/vue in web/ui and the docs site, then copy each icon again with --add.
