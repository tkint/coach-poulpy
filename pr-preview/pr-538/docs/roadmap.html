Roadmap ​

What ships and in which order. A phase is a layer of the product, each added without reworking the one below; a release is a set of features inside a phase that makes sense together, cut when it is ready, not on a date.

Draft. The grouping below awaits the maintainer's approval in #229. Release numbers after the current one are not final, and the GitHub milestones still follow the phases until it is decided. The current version is the latest tag on the Releases page.

A GitHub release plus the server deployed on Infomaniak is production (Releasing). Publishing in the app stores comes in its own phase, at the end.

Phase 2 · Treadmill ​

Runs alongside phase 1, because the treadmill link was the riskiest piece. What is left is #14, choosing what a device measures from its page, which needs a new design first. Releases are cut with the phase 1 release they fall in.

#29 run the shared engine in the browser with Kotlin/JS, then plan, review and run guided sessions.

Library sync or copy, coach links and comments. Not broken into issues yet.

Phase 6 · Stores ​

Publishing beyond GitHub releases: #24 the Apple Developer membership and TestFlight, then the App Store and Google Play. Until then iPhone builds come from Xcode.

Later ​

Wanted, not planned: #225 rethink the workout player and the live recorder as one idea (ADR 0018 stays in force until then), #30 control the treadmill, #31 heart rate straps, #32 user-created exercises, #33 progression rules, #75 guided building of a long run, #124 Poulpy's coaching style, #228 APIs and an MCP server, #481 direct Garmin BLE telemetry.

Not tied to a release ​
