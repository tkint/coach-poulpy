`CpPoulpy` draws one of Poulpy's drawings, decorative unless it has a `label`; `size` is its width in pixels. The drawings are generated from `design/build-poulpy.mjs` and shared by every platform: see Core, Poulpy for all of them, and `PoulpyDrawing` for the names the `drawing` prop takes.

`CpPoulpyCard` draws the empty state pattern, under Web, Patterns, Empty state.

| Vue | Classes |
| --- | --- |
| `<CpPoulpy>` | `img.cp-poulpy` from `design/poulpy/` |
| `<CpPoulpyCard>` | `cp-card bg-secondary text-secondary-content cp-poulpy-card` |
