Decisions

0001 · Local-first: the phone is the source of truth

0002 · One Kotlin Multiplatform core for every platform

0003 · Sessions are stored as append-only event logs

0004 · Workout types are modules over one engine

0005 · Ids are UUIDv7 made on the device

0006 · Sync keeps both conflicting edits

0007 · Postgres: columns for structure, JSONB for content

0008 · A curated catalog with stable slugs, updated without an account

0009 · Shared plans are saved synced or as a copy; enrollments pin a version

0010 · Treadmills are read-only metric sources in v1

0011 · A .FIT file export instead of Garmin and Strava APIs

0012 · Design tokens are generated from one file

0013 · Workouts have a format, not a type

0014 · Text lives in one JSON file per language and namespace

0015 · Catalog text lives in translation files

0016 · Mockups are plain HTML in the repo

0017 · Body measurements are stored metric and shown in the person's units

0018 · Live plays a mixed workout with the workout player's steps

0019 · The server runs with Docker Compose on one server

0020 · Every credential resolves to one caller with scopes

0021 · The landing site, the web app and the API each have their own hostname and container

Design tokens ​

tokens.json is the single source for Coach Poulpy's colours, mood shades, type scale, spacing, radius and motion. Edit it, then regenerate the platform files:

sh
node design/build-tokens.mjs
Generated fileUsed by
app-android/.../ui/PoulpyTokens.ktCoachPoulpyTheme (Material 3 colour scheme, typography, shapes) plus PoulpyPalette, PoulpyMood, PoulpySpace, PoulpyRadius, PoulpyMotion
app-ios/CoachPoulpy/Theme/PoulpyTokens.swiftPoulpyColor (light and dark), PoulpyPalette, PoulpyMood, PoulpyFont, PoulpySpace, PoulpyRadius, PoulpyMotion
app-ios/.../AccentColor.colorset/Contents.jsonThe iOS accent colour (buttons, links, toggles)
web/src/styles/tokens.cssCSS custom properties (--cp-*), with dark values under prefers-color-scheme

CI runs node design/build-tokens.mjs --check and fails if a generated file no longer matches tokens.json.

Colour rules:

  • The poulpy colours (blue, ember, ink) are the mascot's fabric and are the same in light and dark.
  • The blue side (mood.proud, mood.happy, mood.recovering) means the plan is on track; the ember side (mood.annoyed, mood.grumpy, mood.fuming) means a session slipped.
  • The plush blue and ember are too light for white text: buttons use primary (lagoon 600) and grumpy (ember 600).
  • error is a crimson, always shown with an icon and text, so it is never confused with a grumpy Poulpy.

The brand fonts are Baloo 2 (headings) and Nunito (body). The website loads them from Google Fonts. The apps bundle one static file per weight listed under font in tokens.json, in app-android/src/main/res/font and app-ios/CoachPoulpy/Fonts. After changing those weights, rebuild the files and the theme:

sh
pip install fonttools
python3 design/fonts/build-fonts.py
node design/build-tokens.mjs

On iOS, also list any new file under UIAppFonts in Info.plist. Views use .font(.poulpy(.headline)) instead of .font(.headline) to get the system text styles in the brand fonts. Both fonts are under the SIL Open Font License (design/fonts/OFL-*.txt).

Body map figures ​

build-body-map.mjs draws the front and back muscle chart in both builds (wider shoulders, wider hips) and writes it into the profile mockups and into design/body-map.json, which the apps read. The muscle outlines come from design/body-map-source/parts.json, adapted from the MIT-licensed hugobonifay/body-map (see design/body-map-source/NOTICE.md); the script turns them into plain curves, names each muscle, stretches the builds and leaves the skin transparent. To change a muscle, edit the script or the source outlines, then run:

sh
node design/build-body-map.mjs

Poulpy's drawings ​

build-poulpy.mjs draws Poulpy's six mood portraits and twelve poses with the brand book's own drawing code, plus the loading animation's top view and the app icon, and writes them for each platform:

sh
node design/build-poulpy.mjs
Generated fileUsed by
design/poulpy/*.svgReference copies, to look at or reuse on the web
app-android/src/main/res/drawable/poulpy_*.xmlAndroid vector drawables (R.drawable.poulpy_pose_champion)
app-ios/CoachPoulpy/Assets.xcassets/Poulpy/*.imagesetiOS vector assets (Image("PoulpyPoseChampion"))
app-android/src/main/res/drawable/ic_launcher_*.xml, mipmap-anydpi-v26/ic_launcher.xmlThe Android launcher icon: an adaptive icon with a themed (monochrome) layer
app-ios/CoachPoulpy/Assets.xcassets/AppIcon.appiconsetThe iOS app icon: 1024 px PNGs for light, dark and tinted
ic_launcher_<id>_*.xml, mipmap-anydpi-v26/ic_launcher_<id>.xml, AppIcon<Id>.appiconsetThe alternate icons Settings › App icon offers (proud, annoyed, grumpy, champion, cocky), built the same way

Portraits and poses share one 248 × 226 frame, so they can replace each other without moving. The loader (loader, and loader_small with a thicker line for sizes under 32) is Poulpy seen from above as a blue outline of eight round lobes with short tails; PoulpyLoader on Android and iOS turns it clockwise once every 2.4 s (10 s when animations are reduced) and replaces the old Spinning pose. CI runs it with --check too. The shared PoulpyDrawing enum names each drawing, and PoulpyCoach picks which one Today shows.

The app icon is the brand book's: the happy blue Poulpy on Foam (neutral.50), and on Deep sea (theme.dark.background) for the iOS dark icon. On Android, Poulpy is scaled so his farthest arm sits on the 66 dp circle every launcher mask keeps; the themed icon is his silhouette at half strength with the eyes and smile at full. iOS only takes PNGs, so the script rasterises the icon itself, in plain JavaScript so every machine gets the same pixels; --check compares those pixels, not the compressed bytes.

The alternate icons use the portrait or pose of the same name, scaled until its longest side fills 170 of the 200 square (on Android, until its farthest point sits on the 66 dp circle), so a pose with props or confetti draws Poulpy smaller. Their ids are those of AppIcon in the shared code and never change. Android switches between launcher aliases in the manifest; iOS lists the sets in ASSETCATALOG_COMPILER_ALTERNATE_APPICON_NAMES in app-ios/project.yml.

The rules for using Poulpy are in docs/brand.md; the full brand book is in site/public/brand/book.html and on the docs site, and the decisions behind it are in docs/brand-decisions.md.
