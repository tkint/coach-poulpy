Roadmap ​

What ships and in which order. A phase is a layer of the product (architecture); a release is a set of features inside a phase that makes sense together, cut when it is ready, not on a date.

Proposal. The grouping below is a draft for the maintainer to approve in #229. Version numbers and release names are not final, and the GitHub milestones still follow the phases until it is decided. The current version is the latest tag on the Releases page.
