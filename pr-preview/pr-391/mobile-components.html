Mobile components ​

The Android and iOS components, drawn with the values of design/tokens.json. The shape and notes of each one are in the Components table of the design system; the fields every form is built from are in its Base fields table, and each entry links to its sample here. Use the switch to see the samples in light or dark; it is remembered apart from the site's own theme.

Button ​

The four button shapes. One primary button per screen; the grumpy button is only the catch-up action.

Chip ​

Filters, with aria-pressed. On is primary, off is a 1.5 px outline.
