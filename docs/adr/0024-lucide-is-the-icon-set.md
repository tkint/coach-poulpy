# Lucide is the icon set everywhere

Every icon in Coach Poulpy comes from [Lucide](https://lucide.dev): the websites, the web mockups and docs site (ADR 0023), the phone and tablet mockups, and the Android and iOS apps. One set means one drawing style, one stroke weight and one name for each action, whatever the platform.

## What it means

- A new icon is taken from Lucide by its Lucide name (`calendar`, `chevron-left`, `circle-alert`). A platform never draws its own icon for an action Lucide already has.
- Each platform uses the Lucide package for its toolkit. Vue uses [`lucide-vue-next`](https://lucide.dev/docs/packages/lucide-vue-next), the official package. The Android (Compose) and iOS (SwiftUI) packages are not yet chosen: the Lucide package list was not checked when this was written, and the community ports found so far are not confirmed as official. Choosing them, and checking their licences and maintenance, is the follow-up issue ([#282](https://github.com/tkint/coach-poulpy/issues/282)).
- Poulpy's drawings are not icons. They stay generated by `design/build-poulpy.mjs` ([ADR 0012](./0012-design-tokens-generated-from-one-file.md)).
- Icon colour comes from the colour roles in the [design system](../design-system.md#colour-roles), never a raw palette step. An error keeps its icon: crimson, with words.

## Why

- A person who learns one icon meaning in the app finds the same one on the website and in the docs.
- One set can be used across Vue, Compose and SwiftUI with the same names, so mockups, screens and sites can be compared directly.
- Lucide is open source under the ISC licence for its code. Most of its icons come from Feather and are under the MIT licence, which both allow use in the app and sites ([Lucide license](https://lucide.dev/license)).

## Consequences

- Existing icons are not migrated by this decision. Migrating them is a separate issue ([#282](https://github.com/tkint/coach-poulpy/issues/282)), so this record changes no screen.
- Until the migration is done, a mix of icon sets may exist. New icons use Lucide.
- A screen or mockup that needs an icon Lucide lacks says so in its PR. The fix is a new drawing in `design/` that matches Lucide's stroke, not a different set.
