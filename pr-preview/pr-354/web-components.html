Web components ​

The landing site, the web app, the web mockups and this site draw with one package, web/ui: DaisyUI with the Poulpy theme, and a few Vue components on top (ADR 0023). The samples below are those components, in light or dark with the switch (remembered apart from the site's own theme). The rules for using them are in the design system. Under each sample are the classes a web mockup writes, since a mockup is plain HTML and writes what the Vue component renders. Every DaisyUI class carries the cp- prefix (cp-btn, not btn); the few classes of our own (cp-chip, cp-stepper, cp-type-*...) never reuse a DaisyUI name. Tailwind's own utilities (w-full, bg-secondary) have no prefix.

Drawer ​

CpDrawer: the admin's page frame. A full-height sidebar from a large screen up, folded to icons by the button in the top bar; on a smaller screen it slides over the page. It fills the browser window, so it has no live sample here: see it in the Admin mockup.

VueClasses
<CpDrawer>cp-drawer lg:cp-drawer-open with input.cp-drawer-toggle, div.cp-drawer-content (a cp-navbar and the page) and div.cp-drawer-side with label.cp-drawer-overlay
<CpDrawerItem label>li and a button with cp-is-drawer-close:cp-tooltip cp-is-drawer-close:cp-tooltip-right and data-tip; cp-menu-active when current
In the sidebarcp-is-drawer-close:hidden hides a label when folded, cp-is-drawer-close:cp-tooltip cp-is-drawer-close:cp-tooltip-right with data-tip names the icon. The variants carry the cp- prefix.
