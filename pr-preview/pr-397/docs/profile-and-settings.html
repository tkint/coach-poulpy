Profile and settings ​

This page defines the profile fields, body-measurement history, units and pain or rehab behavior. The agreed screen layouts and states live in the Mockups gallery, rather than being repeated here (ADR 0016). Wording rules are in Inclusive by default.

Profile fields ​

Everything is optional and stays on the phone. Each field is only here because something uses it.

Why "sex assigned at birth" ​

The only thing the app needs is a physiological input for estimates, so that is all it asks, and it names it as what it is: assigned at birth, not "biological" or "birth" sex, and not gender. Intersex is offered and Prefer not to say is always available. Gender is never asked, because no feature needs it. See decision 13 for what was set aside. This wording comes from published inclusive-forms guidance and has not yet been read by LGBTQ+ people; that read is still to do and does not block building.

Weight and height logging ​

  • Each entry is a date and a value, added from the Log button and corrected or deleted from the history list. One entry per day; a second one that day replaces it.
  • Height changes slowly, so its screen says a measure every few months is plenty, and teenagers can log as often as they like.
  • A weight going up is never red and going down is never green. Poulpy says nothing about it, there is no BMI and no weight goal unless a later issue adds one the person opts into.
  • Every chart has a text alternative naming its first and last value.

Units ​

The unit system chosen in Settings decides how weight (kg or lb), height (cm or ft and in) and distance (km or mi) are shown and typed. Everything is stored metric, so switching converts and never rewrites; see ADR 0017.

Pain or rehab ​

A person can say where it hurts and choose how long the pain window lasts: 72 hours by default, 1 week, 2 weeks or until they clear it. During that window Poulpy stays on the blue side in the Patched up pose, entries never count as missed, and workouts are never filtered. The body map and its accessibility requirements are defined in the design system; the two body figures are chosen independently of sex assigned at birth and are never used for estimates. See Character rules.
